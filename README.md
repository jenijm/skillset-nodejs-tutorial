# Hello from Node.js

A simple Node.js program that prints:

```text
Hello from Node.js!
```

## Requirements

- Node.js 18 or newer

Check your installed version:

```bash
node --version
```

## Run directly

```bash
node index.js
```

## Run with npm

No external dependencies are required, so `npm install` is unnecessary.

```bash
npm start
```

## Run the automated test

```bash
npm test
```
